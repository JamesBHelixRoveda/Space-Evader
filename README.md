# Space Evader

Ein Ausweichspiel fürs iPhone und den Browser – eine einzige HTML-Datei, kein Internet nötig, läuft offline.

## Deinem Sohn über GitHub geben

Am einfachsten über **GitHub Pages** – dann bekommt das Spiel eine echte Web-Adresse, und der Speicher (Bestenliste) funktioniert dauerhaft.

1. Auf github.com ein neues Repository anlegen (z. B. `space-evader`), sichtbar als **public**.
2. Die Datei `space-evader.html` hochladen und in **`index.html`** umbenennen.
   (Über „Add file → Upload files" die Datei hineinziehen; den Namen kannst du beim Hochladen oder danach über den Stift ändern.)
3. Im Repository auf **Settings → Pages** gehen.
4. Unter „Build and deployment" bei **Source** „Deploy from a branch" wählen, als Branch **main** und Ordner **/ (root)**, dann **Save**.
5. Nach ein bis zwei Minuten erscheint dort oben die Adresse, etwa
   `https://deinname.github.io/space-evader/`

Diesen Link schickst du deinem Sohn.

## Auf dem iPhone als App einrichten

1. Den Link in **Safari** öffnen (nicht als Datei-Anhang – sonst zeigt iOS nur eine Vorschau ohne Funktion).
2. Auf das **Teilen-Symbol** tippen (Quadrat mit Pfeil nach oben).
3. **„Zum Home-Bildschirm"** wählen.

Das Spiel liegt danach mit eigenem Untertassen-Symbol als App auf dem Bildschirm, öffnet im Vollbild und läuft auch offline. Die Bestenliste bleibt erhalten.

## Steuerung

- Finger auf den Bildschirm und das Raumschiff nach links/rechts ziehen; im unteren Bereich auch hoch/runter.
- Am Rechner: Pfeiltasten oder WASD.

## Hinweise

- **Ton und Musik** lassen sich auf dem Startbildschirm getrennt an- und ausschalten.
- Das Spiel hat **50 Level** in 5 Welten (Aliens, Tiere, Bälle, Blüten, Obst); jedes 10. Level ist ein dichteres Abschlusslevel mit eigener, düsterer Musik.
- Die **Bestenliste** kann über „Sicherung" als Datei oder Code exportiert und wiederhergestellt werden.
